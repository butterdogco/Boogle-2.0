# Boogle

Boogle is the world's best search engine, no doubt about it. Make this your default search engine because it is absolutely amazing. This project is no longer being actively maintained and will eventually be replaced/reworked to ButterDog Search, which will not rely on Google Sites.

## What is it actually?

Boogle is a search engine of sorts that hosts a primary search page on our website (this repo) and redirects search requests to our Google Site.
